# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a Bash-based project that calculates simple interest using the principal amount, rate of interest, and time period provided by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Rate of interest per year
- Time period in years

## Output
The calculated simple interest.

## Script
The calculation is performed using the `simple-interest.sh` Bash script.
